# Curio

**Estado:** idea capturada, sin implementar.

Lees un mensaje de un LLM (o cualquier texto), haces clic o pasas el ratón sobre una palabra y
aparece una **descripción completa** ahí mismo. Para curiosos e investigadores: fin del
copiar-pegar-buscar-volver.

Piezas: **entidades** + **lazy loading** (la descripción se genera al hacer clic/hover) +
**modelos pequeños** corriendo **en local con Ollama** (sin API key).

## Cómo retomar esto en otra sesión

1. Lee **`IDEA.md`** — está todo: problema, visión, piezas técnicas, plan de arranque y
   preguntas abiertas.
2. El primer objetivo es un **POC** para probar cosas (ver "Plan de arranque" en `IDEA.md`).
